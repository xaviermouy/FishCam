================================================================================
  FISHCAM SETUP GUIDE
================================================================================
  Default username : fishcam
  Default hostname : fishcam0x  (replace x with the unit number)
  Scripts location : /home/fishcam/Desktop/FishCam/FishCam/scripts/


================================================================================
  PART A — ONE-TIME SETUP  (already done on the SD-card image)
================================================================================

  A1. Turn off Bluetooth
      ────────────────────────────────────────────────────────────────────────

  A2. Install required software
      ────────────────────────────────────────────────────────────────────────
      sudo apt update
      sudo apt upgrade
      sudo apt install python3 cron git

  A3. Download the GitHub repository
      ────────────────────────────────────────────────────────────────────────
      cd /home/fishcam/Desktop/
      git clone https://github.com/xaviermouy/FishCam.git

      chmod +x /home/fishcam/Desktop/FishCam/FishCam/scripts/updateFishCamRepo.sh

  A4. Configure the Raspberry Pi (raspi-config)
      ────────────────────────────────────────────────────────────────────────
      Interfaces  > Enable SSH
      Interfaces  > Enable I2C
      Localisation > Set timezone to UTC
      System      > Boot to CLI
      System      > Change hostname to fishcam01
      System      > Splash screen OFF

  A5. Set up the IMU (Adafruit BNO085)
      ────────────────────────────────────────────────────────────────────────
      Install Python libraries:
          pip install adafruit-blinka                    # must be installed first
          pip install adafruit-circuitpython-bno08x

          NOTE: On newer Raspberry Pi OS you may see an "externally managed
          environment" warning. Add --break-system-packages in that case:
              pip install --break-system-packages adafruit-blinka
              pip install --break-system-packages adafruit-circuitpython-bno08x

      Confirm the sensor is detected on the I2C bus:
          sudo i2cdetect -y 1    # should show 0x4A on the grid

      Lower the I2C baud rate (400 kHz → 100 kHz) for stability:
          sudo nano /boot/firmware/config.txt
          Find:    dtparam=i2c_arm=on
          Replace: dtparam=i2c_arm=on,i2c_arm_baudrate=100000
          Save (Ctrl+O, Enter) and exit (Ctrl+X), then reboot:
              sudo reboot

          Verify after reboot:
              grep baudrate /boot/firmware/config.txt
              # Should show 000186a0 (= 100000 in hex)

  A6. Set up the startup cron job
      ────────────────────────────────────────────────────────────────────────
      crontab -e

      Add the following line:
          @reboot sh /home/fishcam/Desktop/FishCam/FishCam/scripts/fishcamStartup.sh &

      Save (Ctrl+O, Enter) and exit (Ctrl+X).
      Verify the entry was saved:
          crontab -l

  A7. Fix folder ownership (avoids permission errors)
      ────────────────────────────────────────────────────────────────────────
      sudo chown -R fishcam:fishcam /home/fishcam/Desktop/FishCam/

  A8. Enable persistent system journal (survives reboots)
      ────────────────────────────────────────────────────────────────────────
      By default the journal is stored in RAM and lost on reboot.
      Enable persistent storage using raspi-config:

          sudo raspi-config
              > Advanced Options > Logging > Persistent

      Reboot when prompted. Verify persistence by checking that journal
      files are present on disk:

          ls /var/log/journal/

      NOTE: On Raspberry Pi Zero W, the manual approach (mkdir + systemd-tmpfiles)
      does NOT work because systemd-journald-flush.service is absent.
      raspi-config is the only supported method.

  A9. Install the web dashboard dependency (Flask)
      ────────────────────────────────────────────────────────────────────────
      pip install flask

          NOTE: On newer Raspberry Pi OS add --break-system-packages:
              pip install --break-system-packages flask

  A10. Mark the fishcam number on the SD card (with a sharpie)
       ───────────────────────────────────────────────────────────────────────


================================================================================
  PART B — PER-UNIT SETUP  (repeat for every fishcam, even with the SD image)
================================================================================

  B1. Update the GitHub repository
      ────────────────────────────────────────────────────────────────────────
      Manual:
          cd /home/fishcam/Desktop/FishCam
          git fetch origin
          git reset --hard origin/main
          git clean -fd

      Automated:
          bash /home/fishcam/Desktop/FishCam/FishCam/scripts/updateFishCamRepo.sh

  B2. Install WittyPi (v4 mini)
      ────────────────────────────────────────────────────────────────────────
      cd /home/fishcam/Desktop
      wget http://www.uugear.com/repo/WittyPi4/install.sh
      sudo sh install.sh
      # Installs to /home/fishcam/Desktop/wittypi — matches wittypi.install_dir in fishcam_config.yaml

      Add the fishcam user to the i2c group so WittyPi scripts run without sudo:
          sudo usermod -aG i2c fishcam
      Log out and back in (or reboot) for the group change to take effect.

      Fix ownership of the WittyPi directory (installer runs as root, leaving
      files owned by root which prevents configure_wittypi.py from writing logs):
          sudo chown -R fishcam:fishcam /home/fishcam/Desktop/wittypi/

  B3. Configure WittyPi
      ────────────────────────────────────────────────────────────────────────
      Run the FishCam configuration script (no sudo needed):

          cd /home/fishcam/Desktop/FishCam/FishCam/scripts
          python3 configure_wittypi.py

      The script will:
          - Sync the RTC from the current system time
          - Set the on/off schedule (or disable for continuous operation)
          - Set voltage thresholds (low-voltage cutoff and recovery)
          - Set the power-cut delay

  B4. Set the hostname  →  this becomes the FishCam ID
      ────────────────────────────────────────────────────────────────────────
      raspi-config > System > Change hostname to fishcam0x

      NOTE: The FishCam ID is read directly from the hostname at runtime.
      No edit to fishcam_config.yaml is needed for the ID.

  B5. Set the unique buzzer beep count
      ────────────────────────────────────────────────────────────────────────
      Edit: /home/fishcam/Desktop/FishCam/FishCam/scripts/fishcam_config.yaml

      Set buzzer.beep_count to a number unique to this unit:
          fishcam01 → beep_count: 11
          fishcam02 → beep_count: 12
          etc.

      Each unit must have a different beep_count so it can be identified
      acoustically from the recordings.

  B6. Configure WiFi credentials
      ────────────────────────────────────────────────────────────────────────
      Edit: /home/fishcam/Desktop/FishCam/FishCam/scripts/fishcam_config.yaml

      Under the network: section set:
          wifi_auto_connect: true
          wifi_ssid:         "<network name>"
          wifi_password:     "<password>"

  B7. Expand the filesystem
      ────────────────────────────────────────────────────────────────────────
      sudo raspi-config
          > Advanced Options > Expand Filesystem

  B8. Adjust lens focus
      ────────────────────────────────────────────────────────────────────────
      rpicam-hello --timeout 0 --width 1920 --height 1080 --framerate 10

  B9. Adjust camera orientation
      ────────────────────────────────────────────────────────────────────────
      rpicam-hello --timeout 0 --width 1920 --height 1080 --framerate 10

      Set vflip / hflip in fishcam_config.yaml as needed.
      Add coloured tape to the chassis and bottle to mark the "up" side.

  B10. Configure and test power saving mode
       ───────────────────────────────────────────────────────────────────────
       Edit: /home/fishcam/Desktop/FishCam/FishCam/scripts/fishcam_config.yaml
       Adjust the power_saving: section for the deployment scenario.

  B11. Label the chassis
       ───────────────────────────────────────────────────────────────────────
       Add a "fishcam0x" label to the outside of the chassis.

  B12. Physical checks before deployment
       ───────────────────────────────────────────────────────────────────────
       [ ] Coin battery seated on the WittyPi board
       [ ] Frame screws tight
       [ ] Camera ribbon cable firmly connected on both ends
       [ ] O-rings inspected and greased
       [ ] Bottle closed and sealed
       [ ] Pressure test with pump to verify seal


================================================================================
  DIAGNOSTIC TOOLS
================================================================================

  System monitor  (processes, logs, hardware, disk — live dashboard)
  ──────────────────────────────────────────────────────────────────
      cd /home/fishcam/Desktop/FishCam/FishCam/scripts
      python3 monitor_system.py
      # Press r to refresh immediately, q to quit

  IMU live display
  ──────────────────────────────────────────────────────────────────
      cd /home/fishcam/Desktop/FishCam/FishCam/scripts
      python3 monitor_imu.py
      # Press q to quit
      # Safe to run at any time: reads directly from I2C when run_imu.py
      # is not active, or reads from the live CSV when it is.

  Web dashboard  (monitor all fishcams on the network from a browser)
  ──────────────────────────────────────────────────────────────────
      Open dashboard.html in a browser while on the same WiFi network as
      the fishcams. The page auto-discovers all units (fishcam01..20.local)
      and shows processes, acquisition status, hardware, and logs.

      Each fishcam runs a local API server on port 5000; it starts
      automatically on boot via fishcamStartup.sh.
      Access a single unit directly: http://fishcam01.local:5000/

  Power saving status report
  ──────────────────────────────────────────────────────────────────
      bash /home/fishcam/Desktop/FishCam/FishCam/scripts/utils/check_power_status.sh
