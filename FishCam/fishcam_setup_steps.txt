# setup IMU
- pip install adafruit-blinka   # must be installed first                                                                                                                                                                                                                                                                           pip install adafruit-circuitpython-bno08x
- pip install adafruit-circuitpython-bno08x
  If you get a "externally managed environment" warning (common on newer Raspberry Pi OS), add --break-system-packages: 
  pip install --break-system-packages adafruit-blinka
  pip install --break-system-packages adafruit-circuitpython-bno08x

- Enable I2C: Interface Options → I2C → Enable
- confirm the BNO085 is detected:
  sudo i2cdetect -y 1  # Should show 0x4A on the grid
  
- Lower baud rate (from 400kHz to 100kHz)
	sudo nano /boot/firmware/config.txt                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   
	Find the line:                                                                                                                                                                                                                                                                                                    
	dtparam=i2c_arm=on                                                                                                                                                                                                                                                                                                   
	Change it to:                                                                                                                                                                                                                                                                                                       dtparam=i2c_arm=on,i2c_arm_baudrate=100000
	dtparam=i2c_arm=on,i2c_arm_baudrate=100000

    Save (Ctrl+O, Enter, Ctrl+X), then reboot:
	sudo reboot

	To verify the baudrate was applied after reboot:
	grep -r baudrate /boot/firmware/config.txt
	Should show 000186a0 which is 100000 in hex.


5- Setup cron job:

Save the changes by pressing CTRL+O, then press Enter to confirm.

8-Save the system journal across reboots (persistent logging)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        
  By default, the journal is stored in RAM and lost on reboot. Enable persistent storage:                                                                                                                                                                                                                              
  sudo mkdir -p /var/log/journal                                                                                                                                                                                                                                                                                    
  sudo systemd-tmpfiles --create --prefix /var/log/journal  
  sudo systemctl restart systemd-journald
